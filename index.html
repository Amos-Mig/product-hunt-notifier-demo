How you run it

Single Python file, free-tier friendly. Trimmed preview:

# notifier.py — trimmed; the kit ships the full watcher + webhook templates
from ph_notifier import Watcher

w = Watcher(
    keywords=['ai agent', 'vector db'],
    categories=['artificial-intelligence', 'developer-tools'],
    min_upvotes=50,
)
w.on_match(lambda hit: webhook.post(hit.payload))
w.run(interval=120)  # polls Product Hunt every 2 minutes
